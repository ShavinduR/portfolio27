# Space Billiards — Social Media Marketing & Content Production (Social page)

Drop the images for this project here using **exactly these base names** (`.jpg`, `.png` or `.webp`):

| File name | Shows |
|---|---|
| `space-billiards-promo-1` | Promotional creative |
| `space-billiards-promo-2` | Brand visual |
| `space-billiards-reel-cover-1` | 9-ball match highlights |
| `space-billiards-giveaway-1` | Social media giveaway |

Then run:

```bash
npm run images
```

This converts them to WebP, creates the small-screen versions and rebuilds the pages. Until a file exists, the site shows an elegant "coming soon" tile in its place.

Recommended: square (1:1) images, at least 1200px wide. For the reel cover, use a strong frame from the video.
